# Ronin Rig v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an Illustrator document whose structure makes an unriggable character physically impossible, then prove the whole Illustrator → SVG → Rive chain on three parts before drawing the other eighteen.

**Architecture:** Rig geometry exists before any art. A locked `Proxy` layer holds 21 A-posed blocking shapes derived from measured joint positions; every piece of art is generated inside exactly one proxy, so no path can span a joint or be shared between two rig parts. Scripted acceptance gates reject a part before it is accepted, so a failure costs one regeneration rather than a whole character. A three-part vertical slice goes all the way to a moving bone in Rive before the remaining parts are made.

**Tech Stack:** Adobe Illustrator 2026 driven by ExtendScript via `osascript`; Python 3 (stdlib only — no numpy/PIL on this machine) for gates; ImageMagick (`magick`) for raster inspection; Rive desktop via the Rive MCP (`mcp__rive__*`).

## Global Constraints

- Artboard is **2500 × 2500 at `[0, 0, 2500, -2500]`**. Illustrator y is **negative downward**. Never change this — every coordinate in `ronin-proxy-geometry.json` assumes it.
- **Never** call `app.documents.add()` or `app.documents[].close()` from ExtendScript. This previously closed three of the user's documents, two unsaved and unrecoverable. Create files by copying on disk with `cp`, then open by path.
- **Never** script Pathfinder via `executeMenuCommand`. Confirmed to silently no-op twice; a grouped retry hung Illustrator for over two minutes. If a Pathfinder operation is genuinely required, hand it to the user with a pre-made selection.
- Wrap **every** `do javascript` in `with timeout of 600 seconds`. A `d.save()` on a multi-MB `.ai` overruns the default AppleEvent timeout and returns error `-1712` **even though the script completed**. On timeout, re-probe before assuming failure.
- Illustrator **silently deletes a `GroupItem` when its last child is moved out**. Re-assert every expected slot after any bulk move.
- **Re-probe document state at the start of any task that deletes or overwrites.** The user works in the file between turns; a verified saved state was undone mid-session during v3.
- **Render a PNG and look at it after every pass.** Every significant v3 error was invisible in numbers and obvious in one image. Twice, overlap statistics supported conclusions the rendered geometry contradicted.
- Hidden art exports as `display: none` **with a space**. Grepping `display:none` returns 0 and gives a false all-clear.
- SVG `id`s become Rive shape names **exactly**. Spaces and typos ship through to the runtime.
- Rive's children list is the **reverse** of SVG document order: index 0 = drawn last = front.
- Locked palette, two tones per material, no gradients: `#0E0A0C` ink/hakama, `#161B38` navy gi, `#E89359` skin, `#DB3720` sash and headband, `#AD231B` dark red shadow, `#925B3E` boot brown, `#401E20` dark brown, `#FFFFFF` eye whites.
- Total path budget **≈152**. Per-part budgets in Task 4's `BUDGET` dict are authoritative.

| `ronin_rig_v4.ai` | The document. Repo root, beside `ronin_master.ai`. |

```bash
  o.horizontalScale = scale; o.verticalScale = scale;
  DOC.exportFile(new File(path), ExportType.PNG24, o);
```

```bash
cat > scripts/illustrator/gates.py <<'PY'
#!/usr/bin/env python3
"""Acceptance gates for a v4 Ronin rig part. Exit 0 = all pass."""
import json, sys

BUDGET = {'head-face':30,'head-ear':6,'head-hair-back':14,'head-hair-front':10,
 'head-bandana':6,'streamers':6,'neck':4,'torso':12,'pelvis':8,
 'arm-R-upper':4,'arm-R-fore':4,'arm-R-hand':6,'arm-L-upper':4,'arm-L-fore':4,'arm-L-hand':6,
 'leg-R-thigh':4,'leg-R-shin':4,'leg-R-foot':6,'leg-L-thigh':4,'leg-L-shin':4,'leg-L-foot':6}
PALETTE = ['0E0A0C','161B38','E89359','DB3720','AD231B','925B3E','401E20','FFFFFF']
CHAIN = {'arm-R-upper':'arm-R-fore','arm-R-fore':'arm-R-hand',
         'arm-L-upper':'arm-L-fore','arm-L-fore':'arm-L-hand',
         'leg-R-thigh':'leg-R-shin','leg-R-shin':'leg-R-foot',
         'leg-L-thigh':'leg-L-shin','leg-L-shin':'leg-L-foot'}
BOUNDS_TOL = 40      # units a path may exceed its proxy
PALETTE_TOL = 40     # euclidean RGB distance

def rgb(h):
    try: return int(h[0:2],16), int(h[2:4],16), int(h[4:6],16)
    except Exception: return None

def near_palette(h):
    v = rgb(h)
    if v is None: return False
    for p in PALETTE:
        q = rgb(p)
        if sum((v[i]-q[i])**2 for i in range(3)) <= PALETTE_TOL**2 * 3: return True
    return False

def overlap(a, b):
    """fraction of bbox a that lies inside bbox b. boxes are [x0,ytop,x1,ybot]"""
    ix = max(0, min(a[2],b[2]) - max(a[0],b[0]))
    iy = max(0, min(a[1],b[1]) - max(a[3],b[3]))
    area = (a[2]-a[0]) * (a[1]-a[3])
    return (ix*iy)/area if area > 0 else 0.0

def main():
    data = json.load(open(sys.argv[1]))
    want = sys.argv[2:] or sorted(BUDGET)
    proxies, paths = data['proxies'], data['paths']
    fails = []
    for s in want:
        mine = [p for p in paths if p['slot'] == s]
        px = proxies.get(s)
        if px is None:
            fails.append('%s: NO PROXY' % s); continue
        if not mine:
            fails.append('%s: EMPTY' % s); continue

        # 1. path budget
        if len(mine) > BUDGET[s]:
            fails.append('%s: %d paths > budget %d' % (s, len(mine), BUDGET[s]))

        # 2. inside proxy bounds
        for p in mine:
            b = p['b']
            if (b[0] < px[0]-BOUNDS_TOL or b[2] > px[2]+BOUNDS_TOL or
                b[1] > px[1]+BOUNDS_TOL or b[3] < px[3]-BOUNDS_TOL):
                fails.append('%s: path %d escapes proxy: %s vs %s' % (s, p['i'], b, px))

        # 3. no path crosses the joint into the next chain link  (the v2 failure)
        nxt = CHAIN.get(s)
        if nxt and nxt in proxies:
            for p in mine:
                if overlap(p['b'], proxies[nxt]) > 0.55 and overlap(p['b'], px) > 0.55:
                    fails.append('%s: path %d spans the joint into %s' % (s, p['i'], nxt))

        # 4. no path shared with a non-chain slot  (the v3 failure)
        for p in mine:
            for other, ob in proxies.items():
                if other == s or other == nxt or CHAIN.get(other) == s: continue
                if overlap(p['b'], ob) > 0.55 and overlap(p['b'], px) > 0.55:
                    fails.append('%s: path %d is shared with %s' % (s, p['i'], other))

        # 5. palette
        for p in mine:
            if p['c'] in ('none','other','err'): continue
            if not near_palette(p['c']):
                fails.append('%s: path %d colour #%s off-palette' % (s, p['i'], p['c']))

        # 6. no scene-wide outline path
        for p in mine:
            b = p['b']
            if (b[2]-b[0]) > 900 and (b[1]-b[3]) > 900:
                fails.append('%s: path %d is scene-scale (%dx%d) - unified outline?'
                             % (s, p['i'], b[2]-b[0], b[1]-b[3]))

        # 7. the part as a whole fills its proxy - catches scale and position drift,
        #    which is how cropped per-part images destroy the shared coordinate space
        ux0 = min(p['b'][0] for p in mine); ux1 = max(p['b'][2] for p in mine)
        uy1 = max(p['b'][1] for p in mine); uy0 = min(p['b'][3] for p in mine)
        pw, ph = px[2]-px[0], px[1]-px[3]
        aw, ah = ux1-ux0, uy1-uy0
        if pw > 0 and ph > 0 and (aw < 0.55*pw or ah < 0.55*ph):
            fails.append('%s: art %dx%d fills too little of proxy %dx%d - cropped or misplaced?'
                         % (s, aw, ah, pw, ph))

        if not any(f.startswith(s + ':') for f in fails):
            print('PASS %-16s %d paths' % (s, len(mine)))
    for f in fails: print('FAIL ' + f)
    return 1 if fails else 0

if __name__ == '__main__':
    sys.exit(main())
PY
chmod +x scripts/illustrator/gates.py
```
