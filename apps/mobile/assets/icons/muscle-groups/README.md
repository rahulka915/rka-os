# Muscle Group Icons

Runtime destination for custom muscle-group artwork.

Use transparent PNG exports for now, separate from the individual exercise thumbnails in `assets/exercises/`.

Suggested filenames:

- `chest.png`
- `back.png`
- `shoulders.png`
- `arms.png`
- `legs.png`
- `core.png`
- `full-body.png`
- `cardio.png`

Export guidance:

- Square transparent PNG canvas.
- Keep active artwork visually consistent across the set.
- Prefer the simplified soft-object RKA icon style: rounded forms, clear silhouette, moderate depth, no ornate/generic fitness-app clutter.
- Do not include labels or baked backgrounds.
