# Header icon pack v2

Production-ready transparent PNGs for the shared app header:

- `settings.png` — Settings button
- `theme-light.png` — Light-mode toggle state (sun)
- `theme-dark.png` — Dark-mode toggle state (crescent)
- `inbox-empty.png` — Inbox count `0`
- `inbox-active.png` — Inbox count `1...10`
- `inbox-full.png` — Inbox count above `10`

All runtime assets are 512×512 transparent PNGs designed for 34–36pt display inside a minimum 44pt touch target. The green source sheet under `source/` is generation provenance only and must not be loaded at runtime.
